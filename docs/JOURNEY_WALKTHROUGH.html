Functional walkthrough

One loan, start to finish: what to click, what to enter, where it goes next

This follows a new working-capital request of ₹45 Cr from Zeta Foods Private Limited, a fictional company, through all five stages. Each step shows who signs in, what they do and where the application moves.

Before you start

Signing in. Open /los. Pick a group, then Select group →, then pick the user and role, and click Sign in. In this demo there are no passwords.
  • To act as the next person, use Sign out and sign in as them. If the same person holds two roles, switch Active role in the sidebar instead.
  • Your work is under My Queue. Click an application to open its Application Detail.
  • Every application shows a step card at the top. It shows the current step, who holds it, the SLA, a remarks box and the action buttons. A remark is required for every action.
Prepare the demo documents (once): python scripts/make_demo_documents.py demo_documents. You'll upload:
  • at sourcing: request/request_letter.pdf, kyc/certificate_of_incorporation.pdf, kyc/pan_card_scan.pdf and financials/audited_financials_fy2025.pdf;
  • at post sanction: legal/signed_sanction_letter.pdf and legal/facility_agreement.pdf;
  • at disbursement: request/drawdown_request.pdf.
STAGE 1 · PS

Prospect Sourcing

Step 1 · Open a new application

Sign in as Sourcing & Relationship → Ananya Rao → Prospect Sourcing Maker (RM)
  1. In the sidebar, click New Application.
  2. Choose how to start:
    • Existing borrower: the company is already on record. Pick it from Select a borrower…. The Customer identity & deduplication panel loads PAN, CIN, GSTIN, incorporation date, constitution, the core-banking search and any other applications for the same company. Go to (e).
    • New prospect from documents: the company is new to the system. Continue with (c). This is the path for Zeta Foods.
  3. Under Prospect documents, click Add document(s). Add the request letter (category Request), the two KYC files (KYC) and the audited financials (Financials).
  4. Click Read documents with the intake agent.
    The intake agent reads every document at the same time. It fills in legal name, CIN, incorporation date, registered office, facility type, amount (₹45 Cr), tenor (12 months) and purpose. Each value shows its document, page and confidence. It also checks for a borrower with the same PAN, CIN or name, and shows No borrower with the same PAN, CIN or name is on record or lists the matches. A PAN on the scanned card is left empty unless an image-reading model is configured.
    Check the values. Type anything that wasn't read, such as the PAN, and correct anything wrong. If a possible duplicate is listed, confirm it is a different company.
  5. Credit Appraisal Memorandum (CAM) card: choose how the IP Note will be pre-filled.
    • Use the CAM from the CAM workspace: shown when a CAM was already generated for this borrower (date, decision, grade). The facility is pre-filled from it. On Create draft the CAM is linked to the application and fills the IP fields at once; the IP Note step will not generate a second one. The CAM workspace has a Start LOS application button that opens this screen with it selected.
    • Upload the bank's CAM document: choose the PDF, then Upload and read the CAM.
      The CAM intake agent lists the sections it recognised (background, industry, marketing, governance, strengths, weaknesses, risks, financials, security, terms, covenants, deviations, recommendation), each with its page, and the values it read (sector, banking arrangement, ratings, recommended limit, pricing). A CAM with another company's PAN or CIN is refused.
    • For a new prospect, add the CAM with the other documents (category Cam); after Read documents with the intake agent the option Use the bank's CAM among the documents is selected.
    • Generate the CAM when the application is created: the preparation agents generate it in a parallel lane while they read the documents and run the checks.
    • No CAM now: it is generated later, at the IP Note.
  6. Fill in the rest of the form:
    • Sector (required) and Subsector.
    • Sourcing decision: choose Refer for in-principle and add the mandatory-field remarks.
    • Proposed facilities: these are pre-filled from the request letter. Check the nature, amount, tenor and purpose. Use + Add Facility for more.
    • Related parties (optional): add promoters, guarantors and group entities.
    • Prospect discussion: project type, funding type, a brief description, the detailed discussion and initial remarks.
    • Priority: Normal, High or Low.
  7. Click Create draft. The application gets its number (LOS-2026-NNNNN) and opens.
For a new prospect, or when you start from a CAM, the preparation agents start straight away. You'll see Agents preparing… and three lanes running together: identity & duplicate check, API due-diligence checks and document intake. For an existing borrower, click Prepare with agents yourself.

Step 2 · Verify and complete sourcing

Still Ananya Rao (RM), on the application page
  1. Documents & AI prefill: click Accept all high-confidence. Edit any other value, giving a reason.
  2. Due diligence (governed workspace): the API checks have run. If any are pending, click Run all API checks. Then Record each manual check: CRILC, Central Fraud Registry, CEIB, Enhanced Due Diligence, UDIN, KYC and MLRA.
  3. If a mandatory check shows a match, such as a name-screening hit, the Compliance VP (Priya Raghavan) must sign in and record an exception before you can submit.
  4. On the step card, type a remark and click Submit to IP Note.

STAGE 2 · IP

In-Principle

Step 3 · IP Note Processing

Ananya Rao (RM) · SLA 3 days
  1. On the Prepared by agents, verified by you card, click Prepare with agents.
    The credit case (the full CAM analysis of the audited statements) and the due-diligence checks run together. Then one agent per workspace fills the CMA, related parties, securities, exposure, internal rating, pricing, account conduct and the proposal narrative. Finally the IP Note is drafted. Revenue is read as ₹312.40 Cr, not the ₹316.50 Cr total income.
  2. In the verify list, click Select all bulk-eligible, then Confirm selected.
  3. Fields that aren't pre-ticked, such as the drafted narrative, rating and decision fields, need one at a time: read each one and click Confirm, or Change… with the correct value and a reason.
  4. Open the IP Note (Printable view ↗). If it isn't drafted yet, click Generate IP Note.
  5. Type a remark and click Recommend IP proposal.
The step can't be submitted until the IP Note exists, no due-diligence item is blocking, and the IP-stage documents are on file.

Application Processing

Step 11 · Application Note Processing

Ananya Rao (RM) · SLA 5 days
  1. Click Prepare with agents to refresh the workspaces, then verify as in Step 3.
  2. The What to do now panel on My task lists anything that blocks Submit appraisal; Go to … opens the place to fix it. The button stays disabled until the list is clear.
  3. Open Workspaces → Terms & conditions. The T&C agent has drafted the conditions by category (pre-commitment, pre-disbursement, covenants with stipulated values, facility-specific, bank standards) from the credit reassessment and the proposed covenants. Confirm all, or Edit one (a changed wording needs a reason), Remove one (with a reason) or add your own.
  4. If a project was created for a term loan, complete the ESMS screen (Projects & ESMS): the agent has proposed the E&S category and the excluded-activity answer.
  5. If needed, issue the term sheet under Term sheet & sanction letter (Issue).

STAGE 4 · POS

Post Sanction

Step 21 · Post Sanction Maker

Sign in as Operations & Fulfilment → Farah Sheikh → Post Sanction Maker · SLA 5 days
  1. Under Term sheet & sanction letter, Issue the sanction letter and send it to the borrower outside the system.
  2. When it comes back signed, Upload PDF the signed sanction letter and the facility agreement (category Legal).
  3. Click Prepare with agents.
    The agent reads both documents and pre-fills the consent form: accepted by Rohan Desai on 05-Nov-2026, the sanction reference, and the agreement dated 10-Nov-2026.
  4. Check the pre-filled consent and per-facility execution, then click Record sanction consent. Saving an unchanged value counts as confirming it; a changed value is recorded as an override.
  5. In Conditions, deviations and disbursement, mark each condition precedent satisfied (with evidence), deferred (new date and reason) or waived (reason).
  6. If the screen shows Material change(s) since the approval snapshot, for example the new documents, review it and record your decision.
  7. Type a remark and click Submit.
The step can't be submitted until consent is recorded, no condition precedent is open, and material changes are reviewed.

STAGE 5 · DIS

Disbursement

Step 23 · Disbursement Maker

Lakshmi Narayan · Disbursement Maker · SLA 2 days
  1. Upload PDF the borrower's drawdown request (category Request).
  2. Click Prepare with agents.
    The agent reads the request and pre-fills the tranche (₹20 Cr, value date 20-Nov-2026, purpose) and the beneficiary (name, account number, IFSC). In parallel the carry-forward agent fills the disbursement record from what was already sanctioned: the interest terms (benchmark, spread, rate, penal rate), the repayment schedule (Annexure I), the fee collection (the fees approved at AP) and the security details (Annexure IV).
  3. In Workspaces → Disbursement ops, check the carried values. Save a section to confirm it; a value you change is recorded as your correction and is never overwritten by the agents.
  4. Save the beneficiary, then click Record tranche with the pre-filled values.
  5. Complete the disbursement record and the operating checklist. Generate the disbursement memo and click Mark reviewed (I verified the record).
  6. Tick the manual items on the Disbursement checklist: security documents executed, charge registered, limit set up, request received, insurance assigned.
  7. When the card shows Checklist complete and tranche recorded — ready to submit, type a remark and click Submit.

Other moves and what they do

ActionWhereWhat happens
Return / ReworkReviewers, VPs, committeesBack to the stage's maker step, assigned to the person who last worked it. Your remark appears on their step card.
RejectCheckers, committeesThe application ends (REJECTED).
DeferSourcing and IP NoteOn hold until a date you enter. The SLA pauses and only Reactivate is shown.
Drop / WithdrawMaker stepsCloses the application, for the bank's reason or at the customer's request.
Propose modificationPost Sanction MakerRaises a change to the sanctioned terms for re-approval.
Escalate / ReassignAny active applicationFlags it for attention, or moves the step to another eligible person.
Help along the way. Each application has a Next best actions panel. It suggests what to do next, can run a preparatory task for you, drafts return notes and document requests, and answers questions from the record. It never takes a decision.
